تعذر الاتصال بالخادم الرئيسي!

يبدو أن تطبيق الخلفية (Backend API) لم يتم تشغيله بعد على المنفذ 5000، أو لم يتم تهيئة قاعدة البيانات.

لتشغيل الخادم، افتح سطر الأوامر (cmd) في مجلد خادم المشروع واكتب:

cd server
python main.py

تأكد من تشغيل قاعدة بيانات PostgreSQL وتطابق إعدادات ملف .env قبل المحاولة مجدداً.
